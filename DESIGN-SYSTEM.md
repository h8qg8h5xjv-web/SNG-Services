# DESIGN-SYSTEM.md — v2 «окно»

Источник визуала — демо `design-handoff/design-reference.html` и его разбор
`DEMO_MAP.md` (папка в `.gitignore`, лежит локально). Этот файл описывает то,
что реализовано в коде. **Документ = код:** токены — в `app/globals.css`
(`@theme`), классы компонентов — в `app/styles/*.css`, React-примитивы — в
`components/ui/*`. Если код и документ расходятся, чинится одно из двух в том же
коммите.

## Идея

«Окно» — это и окно в доме, и свободное время у мастера («есть окно в 12:15»).

- Янтарное арочное окно = **реальный** свободный слот. Прямоугольные голубоватые
  окна — просто дома. Забронированный слот — окно, которое погасло: время
  остаётся цвета лампы.
- Ночные (dusk) секции — поиск и предложение. Дневные (paper) — понять и выбрать.
  Внутренние страницы открываются ночной шапкой, дальше дневное тело.
- Честность: число окон и янтарные окна — только из настоящих данных
  (`lib/slots`). Нет данных — нет цифры.

## Токены (`app/globals.css`)

| Токен | Hex | Для чего |
|---|---|---|
| `dusk` / `dusk-2` / `dusk-3` | #0F1830 / #16213F / #223056 | Ночь, карточки на ночи, погасшее окно |
| `lamp` | #FFB547 | **Единственный акцент.** Свободный слот, главная кнопка, фокус |
| `lamp-hi` / `lamp-lo` | #FFD591 / #E0892A | Только градиент свечения окна |
| `paper` / `card` | #F3F5F9 / #FFF | День, поверхности |
| `ink` | #121A2E | Текст на дне, текст на янтарной кнопке, выбранное состояние |
| `mute` / `mute-night` | #5E6780 / #A9B3CC | Вторичный текст на дне / на ночи |
| `line` | #DDE2EC | Волосяные линии |
| `err` / `ok` | #B42318 / #1F7A4D | Ошибки форм / статус «взято» |

Промежуточные оттенки из демо тоже токены (`night-soft`, `chip-text`,
`placeholder`, `soft-line`, `dash`, `notice`…), литералов в TSX нет. Hex в TS —
только в `lib/palette.ts` (theme-color, MapLibre, SVG-маркеры).

**Янтарь не для декора.** Не для бейджей, не для выбранного на дне: выбранные
чипы, радио и табы — ink. Исключение, как в демо: ночные чипы в нажатом/текущем
состоянии получают янтарный оттенок рамки.

## Шрифт и типографика

- Display: **Unbounded 500/600** (`--font-display`, класс `.display`) — заголовки,
  время на окнах, цены. Трекинг −0.03…−0.04em, `tabular-nums` для цифр.
- Текст: **Onest 400/500/600** (`--font-sans`). Тело 17px / 1.55 (16px на
  телефоне). Поля — 16px+ на телефоне (без зума в iOS).
- Масштаб: hero h1 `clamp(40px,7vw,100px)`; `.ph1` (h1 страницы)
  `clamp(30px,4.4vw,58px)`; h2 `clamp(28px,3.6vw,48px)`; `.h3`
  `clamp(20px,1.8vw,24px)`; юридический текст 17.5px / 1.65, 68ch.
- Регистр как в предложении. Без капса, без «надзаголовков», без стрелок в
  кнопках.

## Раскладка

- Контейнер `.wrap`: 1240px, боковой отступ `clamp(20px,4vw,48px)` (`--gutter`).
- Брейкпоинты дизайна: телефон ≤720, планшет ≤980, ссылки шапки ≤1080. В
  Tailwind — `tablet:` (≥721), `desktop:` (≥981), `wide:` (≥1081).
- Шапка `--hdr` 68px (60px на телефоне). Липкие колонки — `top: calc(var(--hdr) + 24px)`.

## Движение

- Easing: `--ease-out` cubic-bezier(.23,1,.32,1) — вход/выход; `--ease`
  cubic-bezier(.2,.8,.2,1) — цвет и hover; `--spring` / `--spring-soft`
  (CSS `linear()`) — диалоги и шторки. UI — 150–500ms, выход быстрее входа.
- Переходы страниц (`app/styles/transitions.css`, `components/site/NavMotion.tsx`):
  клик по ссылке — арка открывается от нажатого элемента (300ms); шаги потока —
  сдвиг 12px (240ms); шапка и таб-бар стоят. Назад/вперёд браузера сейчас без
  анимации (Next восстанавливает страницу вне transition).
- Бронь = лампа гаснет: 480ms мерцание до темноты. Отмена — зажигается обратно.
- Hover только под `(hover:hover)`. Нет fade-up-on-scroll. Поднимаются только
  карточки слотов.
- **prefers-reduced-motion:** всё мгновенно, страницы/диалоги/тосты — только
  прозрачность 150ms, без pin, fly и parallax.

## Главная и 3D-город

- Данные: `getFreeWindowsToday(locale)` (`lib/slots/service.ts` →
  `lib/slots/windows.ts`). Окно = мастер × время начала (несколько услуг в одно
  время — одно окно, показываем самую дешёвую). Только опубликованные
  native_booking с `booking_enabled`. Из этого одного списка — янтарные окна
  города, счётчик, «Свободно сегодня» и цифры у категорий.
- Счётчик скрыт, если окон сегодня меньше 5 (`MIN_LIVE_COUNT`); окна при этом
  горят. Окон нет — честное пустое состояние и заявка.
- Город (`components/city/scene.ts`, `three@0.170.0`) грузится динамическим
  import после idle, только на главной, и освобождается при уходе. Уровни
  качества high/mid/phone, governor по p90 кадра, пауза вне экрана и во вкладке
  в фоне. На программном WebGL (нет GPU) город не запускается — остаётся
  статичный силуэт (`components/city/Skyline.tsx`) с тем же числом янтарных
  окон. QA-флаг для headless-скриншотов: `localStorage['sng:city:allow-software']
  = '1'`.
- Живой фильтр (`lib/home/filter.ts`): чипы и ввод сужают город, счётчик и
  ленту вместе; ввод терпит неправильную раскладку.
- Внутренние страницы: силуэт без янтаря (`<Skyline lit={0} />`) в `.nhead`.

## Мастер и запись

- Страница мастера: галерея из реальных фото (нет фото — честная dusk-заглушка),
  бейджи только из данных (`Язык проверен` = verified-язык, страховка/DBS =
  проверенные документы, `Выезд на дом` = `travels_to_client`), услуги,
  «Где и когда», контакты. Справа `ListingWeek`: реальные окна на 7 дней
  (`WeekPicker` → `getSlots`), время ведёт прямо на шаг «Контакты».
- Запись (`BookingFlow`): шаги в URL `?step=service|time|details|done&svc=&slot=`.
  Ссылка с `svc`+`slot` без шага (карточки главной) открывает «Контакты».
  «Контакты» перепроверяют окно; занято — notice и возврат к выбору времени.
  Готово: окно гаснет (380ms → 480ms мерцание), «Добавить в календарь» (.ics
  из `lib/booking/ics.ts`). Шаги сдвигаются view transition (`setNavKind`).
- Заявки: та же форма и логика, v2-оформление; статус — «тред» с ответами
  мастеров (`.rep`), без выдуманного «печатает…».

## Каталог, категория, поиск, «Рядом»

- Одна строка мастера для всех списков — `BusinessRow` (`.rrow`): миниатюра
  (фото или инициалы на dusk), имя-ссылка на всю строку, факты, одна строка
  описания, бейджи из данных, справа до 3 реальных окон сегодня (`.tbtn`,
  ссылка на «Контакты») или «Сегодня окон нет». Список — `ProviderGrid`
  (`FlipList`: перестановка 220ms при смене фильтров).
- Внутренние страницы открываются `NightHeader` (силуэт без янтаря).
- Категория: `CategoryToolbar` — «Район» (мультивыбор в диалоге, живое
  «Показать N»), «Документы проверены», «Выезд на дом», сортировка,
  «Список / Карта». Всё в URL.
- `/catalog`: индекс категорий — название, кто в каталоге, окна сегодня.
- «Рядом»: MapLibre слева, список видимых на карте справа; на телефоне карта
  сверху, список — шторка. Маркеры ink/dusk (янтарь — только окна).

## События (`app/styles/events.css`)

- Одна строка события для всех списков — `EventRow` (`.erow`): арочный
  dusk-блок даты, название-ссылка на всю строку, тип · время · место,
  `Attendance` (инициалы, без имён целиком), справа цена («Бесплатно» или
  «от £X»). Используется в афише, в «Ещё в афише» и на странице мастера.
- Афиша: `NightHeader` с чипами «когда» (в URL), группы по дням (`.ev-group`),
  список в `FlipList`.
- Страница события: `NightHeader` с крошками и фактами (`.ev-facts`), обложка
  только если есть реальное фото, описание, организатор, «Как добраться»
  (`AddressMap`), «Ещё в афише» (3 ближайших). Справа `card.tix`: цена,
  внешняя ссылка на билеты организатора (оплаты у нас нет), «Кто идёт» и
  `GoingButton`. На телефоне — `cta-bar`, если есть ссылка на билеты.

## Доступность

- Фокус: 2px `lamp` + внутреннее кольцо 2px ink (на дне) или dusk (на ночи) —
  3:1 на обоих фонах. После навигации фокус на `h1` страницы.
- Контраст текста ≥ 4.5:1, цели касания ≥ 44px (`pointer:coarse`), поля ≥ 16px
  на телефоне, порядок заголовков, skip-link, `aria-current`/`aria-pressed`.

## Проверка стилей (`npm run check:styles`, запускается в prebuild)

- Запрещены произвольные значения Tailwind (`text-[..]`, `p-[..]`…). Нужен новый
  размер — токен в `@theme` или класс в `app/styles`.
- Запрещён `style={{ … }}`. **Исключение:** объект только из CSS custom
  properties — `style={{ '--i': index }}`. Он передаёт данные правилу в CSS
  (задержки stagger, прогресс) и ничего не стилизует сам.
- JS может менять `element.style` для покадровой анимации (перетаскивание
  шторки, магнитные кнопки, 3D-город) — это не разметка.

## Переходный период

`app/styles/legacy.css` и legacy-токены в `@theme` (`accent`, `text-body`,
`rounded-card`…) — старая синяя система для страниц, которые ещё не
перенесены. Каждый блок удаляется вместе с последним своим пользователем.
Новое туда не добавляется.
